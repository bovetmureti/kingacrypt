The exposure

Today’s encryption already has an expiration date.

Harvest-now, decrypt-later is a present risk for banks, payment rails, and government records. Kenya has no post-quantum mandate yet. Waiting for one is the expensive option.

Global vendors know the NIST standards. Local cyber firms know the buyers. Almost no one can change a Kenyan production system to ML-KEM and ML-DSA without breaking it.

How we work

Research keeps the work honest. Partners supply the boxes.

  1. Inventory first

    We find RSA, ECC, and aging certificates before we propose a migration. No algorithm talk until the map is real.

  2. Hybrid, then cutover

    Systems stay available. Classical and post-quantum run together until the new path is proven.

  3. Implement in production

    We use validated libraries. We do not invent new algorithms. We do not sell HSMs. If you need hardware, we bring a partner.

  4. Leave the skill behind

    Operators, not only consultants, should be able to rotate algorithms when the next standard lands.
